# 노뮤트 편집기 자막 테스트

## ⓪ 개요
- **내용**: 자막 생성기 동작 확인용 짧은 인사·소개 클립. 인사 → 테스트 목적 안내 → 날짜 고지 순.
- **화자**: 1인(테스트 진행자)
- **메타**: 0:05 · 한국어 · 한국어 원본 모드 · 조각 4개

「원본 구절 수: 3개 → 자막 조각 수: 4개」 (13자 초과 문장 1개를 성분 경계에서 시간 2분할)
