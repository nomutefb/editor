유튜브 숏폼 · 장면 그림

맥에서 장면 그림 켜기ChatGPT 구독으로 그림 그리기(Codex)

맥이 켜져 있고 Codex에 ChatGPT로 로그인돼 있으면, 유튜브 숏폼의 장면 그림을 네 ChatGPT 구독으로 그려. API 요금은 따로 안 나가. 맥이 꺼져 있으면 GPT 이미지·입체는 모션 그래픽으로, 그록은 첫 그림 없이 바로 영상으로 자동으로 만들어져. 한 번만 해두면 돼.

1Codex 설치

맥의 터미널 앱을 열고 아래 한 줄을 붙여넣어. 홈브루가 있으면 이게 제일 간단해.

brew install --cask codex

홈브루가 없고 Node가 있으면: npm install -g @openai/codex

설치 확인:

codex --version

2ChatGPT로 로그인

codex login

브라우저가 열리면 ChatGPT 계정으로 로그인해. 확인:

codex login status

ChatGPT로 로그인됐다는 문구가 나오면 성공이야. "API key"가 나오면 codex logout 후 다시 codex login.

3두 번째 계정 (선택)

구독 계정이 2개면 두 번째 계정을 따로 로그인해 둬. 첫 계정 한도가 차면 자동으로 넘어가.

mkdir -p ~/.codex-2
CODEX_HOME=~/.codex-2 codex login --device-auth

터미널에 나온 주소와 코드를 시크릿 창에서 열어 두 번째 계정으로 로그인해. 일반 창은 첫 계정으로 바로 들어가 버려. 확인:

CODEX_HOME=~/.codex-2 codex login status

폴더 이름은 ~/.codex-로 시작하면 돼(3번째 = ~/.codex-3).

4그림 1장 시험

이번 업데이트가 맥에 자동 설치된 뒤(머지 후 최대 약 1시간 안)에 실행해:

bash ~/nomute_ys_driver.sh --selftest

✅ 성공이 나오면 ~/nomute-ys/selftest/test.png를 열어서 그림을 확인해. ❌가 나오면 그 줄을 그대로 알려줘.

5표시등 확인

에디터 → 영상 스튜디오 → 유튜브 탭의 "장면 그림" 옆 표시등:

표시뜻
맥 켜짐그림을 그릴 수 있어. 1분마다 갱신돼.
맥 꺼짐3분 넘게 신호가 없어. 이때 만들면 GPT 그림 대신 모션 그래픽으로 나와.
로그인 필요맥은 켜져 있는데 Codex가 ChatGPT로 로그인돼 있지 않아 → 2단계.

6맥이 잠들지 않게

맥이 잠자기에 들어가면 "꺼짐"으로 보여. 전원을 연결하고 시스템 설정의 에너지(배터리) 항목에서 디스플레이가 꺼져도 자동으로 잠자지 않게 켜 둬.

!꼭 알아둘 것

  • 로그인 정보는 맥의 ~/.codex/auth.json에 저장돼. 비밀번호처럼 다뤄 — 채팅·메신저·깃에 절대 붙이지 마.
  • 그림은 글자 작업보다 구독 한도를 3~5배 빨리 써(OpenAI 공식 안내). 장면 7개 = 그림 7장.
  • 한 장면이 실패해도 영상은 나와. 그 장면만 모션 그래픽으로 채워져.
