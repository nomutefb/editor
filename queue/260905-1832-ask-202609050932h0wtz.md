# 🤖 "AGI 시대" 선언한 GPT-6, 종합 지능은 전작과 비슷했다

## 🧷 한줄 요약
오픈AI가 3일(현지시간) 차세대 플래그십 모델 'GPT-6 아스트라'를 공개하며 AGI 시대 진입을 선언했지만, 독립 분석기관이 매긴 종합 지능 지수는 61.2점으로 전작 수준에 머물렀다.

## 📰 Fact (확인된 사실)
- 오픈AI가 사전 학습·강화 학습·정렬 기술을 집약한 차세대 플래그십 모델 'GPT-6 아스트라(Astra)'를 공개했다. 그렉 브록먼 오픈AI 사장은 3일(현지시간) 출시와 함께 "AGI 시대에 오신 것을 환영한다(Welcome to the AGI era)"는 메시지를 전달했다.
- 브록먼 사장은 "몇 년 뒤 범용인공지능(AGI)이 언제 만들어졌는지를 돌아본다면 이 시점, 이 모델일 수 있다"고도 말했다(아시아경제).
- 벤치마크: 프론티어매스 티어 4 97.6%(전작 GPT-5.6 솔 83% — 아시아경제), 익스플로잇벤치 100%, GPQA 다이아몬드 96.0%, 에이전트의 마지막 시험 59.3%(클로드 오퍼스 5 55.5%·GPT-5.6 솔 53.6%), 터미널벤치 4.0 57.9%(GPT-5.6 솔 37.3%·클로드 페이블 5.1 55.8%).
- 추론 평가 'ARC-AGI-3'에서 인간 성능을 넘어섰다. 점수는 **원문(AI타임스) 98.6% / 아시아경제 등 다른 매체 99.9%로 엇갈린다**(아시아경제는 전작 7.8%로 비교). 아시아경제는 DeepSWE v1.1 74.1%, OS월드 2.0 72.6%(전작 65.7%)도 함께 보도했다.
- OS월드 2.0 컴퓨터 이용 환경에서 기존 모델 대비 작업 시간을 약 47% 단축했다. 목표 범위를 벗어나는 자율 행동 오류율은 전작 48.2%에서 0%로 줄었다.
- 세션 간 검색 가능한 메모리 보존(Context Retrieval)을 새로 도입해 대규모 리팩토링·디버깅 완성도를 높였다.
- API 기본 가격은 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러다. 오픈AI 측 설명으로는 성능 대비 API 비용이 이전 세대보다 최대 30% 이상 저렴하고, 터미널벤치 4.0 기준 과제당 추정 비용은 GPT-5.6 솔 대비 약 9%·클로드 페이블 5.1 대비 약 63% 절감된다. 패스트 모드는 표준 대비 최대 2.5배 빠르다.
- **가격을 다르게 읽은 보도**: 아시아경제는 같은 가격표를 두고 토큰 단가 자체가 전작 대비 2.5배 인상됐다고 전했다(제목 「가격도 2.5배↑」).
- 독립 분석기관 아티피셜 애널리시스 종합 지능 지수(AAII)는 61.2점으로 GPT-5.6 솔과 비슷한 수준이다. 페이블 5.1보다 5점 낮고 메타 '뮤즈 스파크 1.3'에도 미치지 못한다. 반면 같은 기관의 코딩 에이전트 지수에서는 67.0점으로 최고점을 기록했다.
- 아티피셜 애널리시스는 "코딩 에이전트 성능과 토큰 효율은 개선됐지만, 종합 지능 지표에서는 전작과 큰 차이가 없었고" 가격 인상으로 "일반 작업 비용 효율은 오히려 낮아졌다"고 지적했다(아시아경제).
- 보안: 6~8월 신규 취약점 환경 평가에서 미지의 제로데이 취약점 2건을 사전에 자체 발견해 해당 기업에 제보했다. 오픈AI는 '데이브레이크(Daybreak)' 프레임워크 기반 안전장치와 원격 강화 모니터링으로 방어적 보안 연구 중심 활용을 제한적으로 병행한다.
- 배포: 현재 일부 기업 우선 공개, 며칠 내 챗GPT 플러스·프로·비즈니스·엔터프라이즈와 오픈AI API, AWS 베드록으로 순차 제공 예정이다. 파이낸셜타임스는 앤스로픽에 내줬던 기술 주도권을 되찾고 기업용 AI 시장 선도 지위를 재확인하는 행보로 평가했다(아시아경제 인용).
- **수능 만점 건(운영자 요청 확인 결과)**: 이번 공개 자료와 국내 보도(검색 확인 범위)에서 아스트라의 한국 수능 응시·만점 관련 성적은 **확인되지 않았다**. 공개된 성적은 전부 프론티어매스·ARC-AGI-3·GPQA 다이아몬드 등 국제 벤치마크 기준이다.
- 출처: AI타임스(임대준) / 교차 확인: 아시아경제(이은서).

## 🔎 Inference (추론·해석)
- 설계 우선순위가 '지식 점수'에서 '실행 능력'으로 옮겨간 세대다. 오픈AI 스스로 범용 텍스트 지능 향상 대신 에이전틱 연동·컴퓨터 UI 조작·코딩·보안·토큰 절감에 최적화했다고 밝혔고, 지수 성적표가 그 선택을 그대로 반영한다. [확신 높음]
- 'AGI 시대 진입' 선언의 수위는 측정치보다 시장 포지셔닝에 가깝다. 종합 지능 지수가 전작 수준인데도 선언은 최고조였고, 앤트로픽과의 주도권 경쟁 구도가 배경에 있다. [확신 중간]
- 토큰 단가 인상은 과금 무게를 장시간 다단계 에이전트 작업 쪽으로 옮긴다. 과제를 끝까지 자동으로 끌고 가는 워크로드일수록 유리하고, 단발 질의 위주 서비스는 체감 비용이 늘어날 수 있다. 아티피셜 애널리시스가 "일반 작업 비용 효율은 오히려 낮아졌다"고 본 지점과 겹친다. [확신 중간]
- 제로데이 자체 발견은 방어와 공격 양면에 동시에 쓰이는 역량이라, 데이브레이크 안전장치와 원격 모니터링을 함께 내건 것은 규제·오남용 대응 성격이 크다. [확신 중간]

## 🧭 다각도 해석
- **실증 우선**: 회사 홍보가 아니라 실제 실무 평가에서 경쟁 모델을 앞섰고 미지의 제로데이 2건을 스스로 찾아냈다는 점에서, AGI 선언은 과장이 아니라 측정된 도약이라는 해석.
- **지표 회의**: 독립 기관의 종합 지능 지수가 전작과 같은 자리라면 '압도적'은 회사가 고른 평가 항목 안에서만 성립한다는 해석. 벤치마크 선택권이 곧 세대 교체 선언권이 되는 구조를 문제 삼는다.
- **비용 실용**: 개발자에게 판정 기준은 지수가 아니라 청구서라는 해석. 토큰 단가가 2.5배 올라도 과제당 비용이 줄면 도입은 늘고, 반대로 단발 질의 서비스는 그대로 손해를 본다.
