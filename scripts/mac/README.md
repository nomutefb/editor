> `grep -rn "scripts/mac"` 가 홈·레포 전 스크립트에서 0건 = 깃→~/ 복사 코드가 존재하지 않는다.

> 고칠 때마다 `cp ~/nomute_*.sh scripts/mac/` 로 되올리고 커밋할 것.
