# 픽셀 펫 — 그림 1장을 111칸으로 쪼개 돌리는 부품

## 이 폴더가 뭔가
운영자가 리포지 맨 위에 올려둔 펫 스프라이트 사진을 여기로 옮기고, 그걸 실제로 화면에서 돌릴 수 있는 부품으로 만들어 뒀다.
**아직 어느 화면도 이 부품을 부르지 않는다** — 지금 넣으라는 지시가 아니었으므로 붙일 준비까지만 해 둔 상태다.

| 파일 | 뭔가 |
|---|---|
| `nm-pet.js` | 부품 본체. 그림을 111칸으로 쪼개 초당 30장으로 돌리고, 가끔 화면 구석에 들어와 서성이다 화면 밖으로 걸어 나간다 |
| `nm-pet.css` | 부품 스타일. 정본(`viewer/index.html` 픽셀 펫 블록) 값 사본 |
| `펫_데모.html` | 만지는 데모 1파일. 그림까지 안에 넣어 뒀으니 **더블클릭하면 바로 돈다**(폰도 됨) |
| `build_pet_demo.py` | 데모·실측표 생성기 |
| `frames.json` | 111칸 실측표(칸마다 몸 크기·발 위치·자세) |
| `_데모_템플릿.html` | 데모의 틀 |
| `원본업로드_260817_아틀라스_jpg판.jpg` | 운영자가 올린 사진 원본(보관용) |

## 알아둘 것 두 개
1. **올린 사진은 이미 리포지에 있던 그림이다.** `viewer/pet_crab.png`(1320×1080)와 실루엣이 99.3% 같다. 올린 쪽은 배경이 검정으로 굳은 사진 판이라 화면에 얹으면 검은 사각형이 남는다 → 부품은 배경이 비어 있는 원본(`viewer/pet_crab.png`)을 쓴다. 올린 사진은 보관만 한다.
2. **돌리는 로직도 이미 있었다.** `viewer/index.html`의 픽셀 펫 블록(운영자 260710)이 그것이고, 스위치가 꺼진 채(`PETCRAB_ON = false`) 잠들어 있다. 이 부품은 그 로직을 그대로 옮긴 것이고 등장·사라짐·서성임 값은 전부 거기서 가져왔다(새로 지어낸 값 없음).

## 실측값
- 그림 1320×1440 · 한 칸 132×120 · 10칸씩 12줄 · 실제로 쓰는 건 111칸(배회 82 + 퇴장 29)
- 발이 닿는 자리가 전 칸에서 67px로 맞춰져 있다(걸음 폭 때문에 ±15.5px만 흔들림) → 칸을 그냥 바꿔 끼워도 발이 안 흔들린다
- **앉은 자세 45칸 ↔ 일어선 자세 37칸이 네 번 번갈아 나온다**
  - 앉음 `0~13 · 23~28 · 38~43 · 53~58 · 69~81`
  - 서기 `14~22 · 29~37 · 44~52 · 59~68`

## 지금 값 = 크기 절반 · 쉬지 않고 기어다님 (운영자 260817)
정본에서 세 가지를 바꿨다. 원본 동작으로 되돌리려면 각 줄 옆 괄호 값으로 두면 된다.

| 바꾼 것 | 지금 | 원본 | 왜 |
|---|---|---|---|
| 크기 | 0.5 | 0.75 | 「크기 50%」 지시 · 원본의 절반이라 한 칸이 66×60 정수로 떨어져 픽셀이 안 뭉개진다 |
| 돌리는 그림 | 걸음 18칸 | 82칸 전체 | 원본 순서는 절반 넘게(45칸) 정면으로 앉아 있고 그 그림은 다리가 한 화소도 안 움직인다 = 기어다니는 모습이 안 된다 |
| 멈춤 확률 | 0 | 0.002 | 걸음 칸만 돌리면 멈춘 동안에도 다리가 계속 움직여 제자리걸음으로 보인다(실측 = 표본의 26.7%) |

**걸음 18칸을 고른 근거** — 원본은 「정면 정지 → 걸음 → 정면 정지」를 네 번 반복하고, 걸음 사이클은 두 종류가 좌우 대칭이다(다리 변화량 521 대 522 · 발 딛는 중심 52~67 ↔ 67~83). 즉 한쪽만 반복하면 같은 발만 딛고, 두 개를 이어 붙이면 걸음 한 주기가 완성된다. 이어 붙인 자리도 안 튄다(실제 렌더에서 연속 변화 최대 2877 = 사이클 안 평균 2322 수준 · 멈춘 프레임 0).

**멈출 때 앉히고 싶으면** — `pauseChance`를 0.002로 되살리고, 멈춘 동안 앉은 칸(`sitFrames` 중 하나)을 보여주는 배선을 같이 넣어야 한다. 지금은 안 넣었다.

## 화면에 붙일 때 (지금은 안 붙어 있음)
1. `nm-pet.css` · `nm-pet.js` 두 파일을 `viewer/`로 복사
2. 붙일 화면 머리에 두 줄
   ```html
   <link rel="stylesheet" href="nm-pet.css">
   <script defer src="nm-pet.js"></script>
   ```
3. 시작 한 줄 (아무 값도 안 주면 = 크기 절반으로 왼쪽 아래 메뉴 위를 기어다닌다 · 12~35초 뒤 첫 등장, 그 뒤 1.5~4분마다)
   ```js
   nmPet.start();
   ```
   값을 바꾸려면 데모에서 만져 보고 [값 복사]로 나온 줄을 그대로 쓰면 된다.

### 손잡이
| 이름 | 뜻 | 정본값 |
|---|---|---|
| `scale` | 크기 배율 | 0.5 |
| `bottom` | 바닥에서 띄울 높이 | 58 |
| `side` | 서성일 쪽 (`left`/`right`) | left |
| `span` | 돌아다닐 폭(화면 비율) | 0.55 |
| `fps` | 그림 넘기는 속도 | 30 |
| `speedMin`/`Max` | 걷는 속도 | 16 / 30 |
| `loopFrames` | 돌릴 칸 목록. 비우면 원본 82칸 순서 | 걸음 18칸 |
| `pauseChance` | 가끔 멈출 확률 | 0 |
| `stayMin`/`Max` | 한 번에 머무는 시간 | 14000 / 26000 |
| `gapMin`/`Max` | 다시 올 때까지 | 90000 / 240000 |
| `host` | 특정 상자 안에서만 돌게 | 없음(화면 전체) |
| `sitFrames` | 앉은 칸 목록. 비우면 정본 그대로 | 실측 45칸 |

- `nmPet.show()` 지금 등장 · `nmPet.hide()` 퇴장 · `nmPet.stop()` 상시 가동 정지 · `nmPet.set({…})` 도는 중 값 갱신
- 움직임을 줄이는 기기 설정이 켜져 있으면 아예 나오지 않는다(장식이라 접근성 우선 · 정본 계약)
- 클릭을 막지 않는다(`pointer-events` 없음) · 화면 읽기 프로그램에서도 무시된다

## 그림을 갈아 끼울 때
1. `viewer/pet_crab.png`를 새 그림으로 교체(칸 크기·칸 수가 달라지면 `build_pet_demo.py` 위쪽 상수도 같이)
2. `python3 apps/pet/build_pet_demo.py` — 자세를 다시 재고 데모를 다시 굽는다
3. 앉은 칸 목록이 달라졌으면 **생성기가 그 자리에서 멈추고 갈아 넣을 줄을 알려 준다**(부품 목록이 조용히 낡는 걸 막는 검문)

`펫_데모.html` · `frames.json` = 기계가 만드는 파일이라 손으로 고치지 않는다(고치려면 생성기나 템플릿을 고쳐 다시 돌린다).

## 퇴장 동작 = 뒤 29칸 (운영자 260817 2차 「첨부 동작을 이어 붙이고 화면 밖으로 사라지는 걸로」)

**전** — 머무는 시간이 끝나면 제자리에서 서서히 투명해졌다(opacity 페이드 0.7초).
**후** — 마무리 동작을 한 번 보여준 뒤 **걸어서 화면 밖으로** 빠져나간다. 다 나가면 그 자리에서 정리한다.

### 그 29칸을 어떻게 만들었나
운영자가 준 화면 녹화(115프레임 · 1.93초 · 166×190)를 아틀라스 규격으로 다시 구웠다. 새로 그린 그림은 없다.

| 단계 | 한 일 | 실측 |
|---|---|---|
| 1 | 몸통(주황)과 눈을 골라내 압축 얼룩을 걷어냄 | 눈 판정 = 위아래가 몸으로 막힌 구멍만(다리 사이 틈은 바닥으로 열려 있어 자연 제외) |
| 2 | 기존 그림과 같은 크기로 맞춤 | 배율 0.9055 = 아틀라스 0번 칸(76×51)과 녹화 1번 프레임(86×55)이 같은 자세라 1:1로 잼 |
| 3 | 기존 그림의 두 색으로 다시 칠함 | 몸 (214,117,84) · 눈 (0,0,0) — 아틀라스에서 실측한 값 그대로 |
| 4 | 발 닿는 선과 가로 중심을 맞춰 칸에 앉힘 | 접지선 y=118 = 기존 82칸 전부와 같은 자리(새 29칸도 전건 118) |
| 5 | 이어지는 같은 그림은 한 장으로 합침 | 115프레임 → 29칸(30장/초로 0.97초) |

⚠ **격자 복원은 실패했고 그래서 안 썼다** — 녹화가 압축 영상이라 픽셀 경계가 번져서 격자 주기를 못 찾았다(엣지 52개 중 노이즈 다수). 대신 위 5단계(정합 후 재양자화)로 계단을 되살렸다. 결과는 `apps/pet/펫_데모.html`을 열어 눈으로 볼 수 있다.

### 나가는 속도
`exitSpeedMul` 4 = 배회 속도의 4배. 배회 속도(16~30px/s)는 목적 없이 서성이는 값이라 그대로 쓰면 화면 밖까지 10초가 걸려 「사라진다」로 안 읽힌다(폰 430 실측 = 최대 이동거리 302px). 4배면 2.5초라 마무리 동작 0.97초와 합쳐 3.5초 안에 끝난다.

### 되돌리려면
`exitFrames`를 빈 배열로 두면 종전 페이드아웃 퇴장 그대로다(그림 29칸은 남아 있고 안 쓰일 뿐).

- x가 −68.3px까지 밀려 몸이 완전히 화면 밖으로 나감(폭 66px)
