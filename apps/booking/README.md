# 객실 선택 (예매자 좌석 선택)

문자로 링크를 보내면 예매자가 폰 웹에서 열어 **휴대폰 뒷 4자리로 본인 확인 → 객실 선택**까지 하는 프로그램.
이 폴더 하나로 완결된다(노뮤트 에디터 코드와 서로 안 물린다 · 다른 저장소·다른 계정으로 통째로 옮겨도 그대로 돈다).

```
apps/booking/
  public/index.html          예매자 화면
  public/admin.html          관리자 화면(명단·수량·현황)
  functions/api/book.js      서버
  test.mjs                   검증 (node test.mjs)
  인수인계.md                 다음 세션·다른 계정용 인수인계서
```

> 코드를 고치거나 다른 저장소로 옮길 거면 **`인수인계.md` 부터 읽어라** — 파일 지도·계약 3종·실측값·다음 후보가 거기 있다.

---

## 1. 어떻게 도는가

1. 예매자가 링크를 연다 → **뒷 4자리 입력**
2. 명단에 있으면 통과, 없으면 막힌다
3. 명단에 적어둔 **구분(a·b·c)** 에 해당하는 남은 객실만 보인다
4. 스탠다드 더블 / 스탠다드 트윈 중 하나를 고르면 그 자리가 즉시 빠진다
5. 같은 번호로 다시 들어오면 **자기가 고른 내역**만 뜬다(다시 못 고른다)

기본 수량 — A: 더블 5 · 트윈 5 / B: 더블 8 · 트윈 7 / C: 더블 8 · 트윈 7 (관리자 화면에서 바꿀 수 있다)

## 2. 두 사람이 동시에 마지막 한 자리를 눌러도 안 겹친다

수량을 한 파일에 적어두고 빼는 방식이 아니다. **선택 1건 = 파일 1개**를 각자 자기 번호로 만들고,
만든 뒤 전체를 다시 세어 정원 안에 드는지 확인한다. 밀렸으면 자기 파일을 지우고 "방금 마감됐어요"로 답한다.
순서 기준이 (시각, 뒷4자리)라 두 요청이 같은 판정을 내리므로 **한 명만 살아남는다.**
검증 = `node test.mjs` 의 [5]번 (6명 동시 클릭 · 남은 4자리 → 성공 정확히 4명).

## 3. 설치 (한 번만)

Cloudflare Pages에 **새 프로젝트**로 붙인다. 에디터 화면(edit.nomute.kr)은 로그인 벽 뒤라
고객이 문자 링크로 못 들어오기 때문에 따로 떼어 놓는 것이다.

1. Cloudflare → Workers & Pages → **Create → Pages → Connect to Git** → 저장소 `nomutefb/editor`
2. 빌드 설정
   - **Root directory** : `apps/booking`
   - **Build command** : 비움
   - **Build output directory** : `public`
   - Framework preset : None
3. 만들어진 프로젝트 → **Settings → Bindings → R2 bucket**
   - Variable name : `R2` (이 이름이어야 한다)
   - Bucket : `editor` (다른 버킷도 된다 · 키는 전부 `booking/` 밑에만 쓴다)
4. **Settings → Variables and Secrets** → `BOOK_PIN` = 관리자 비번 (아무 문자열)
   - 이 값이 없으면 관리자 화면은 통째로 잠긴다(빈 비번으로 열리는 일 없음)
5. 배포되면 주소가 나온다
   - 고객 링크 = 그 주소 그대로
   - 관리자 = 그 주소 + `/admin.html`

## 4. 쓰는 순서

1. 관리자 화면(`/admin.html`)에 들어가 비번 입력
2. **명단 등록** — 한 줄에 한 명씩. 엑셀 세 칸을 그대로 복사해 붙여넣어도 된다.
   ```
   1234, a, 홍길동
   5678, b, 김철수
   9012, c
   ```
   - 첫 칸 = 휴대폰 뒷 4자리 (숫자 4자리)
   - 둘째 칸 = 구분 a / b / c
   - 셋째 칸 = 이름 (없어도 된다)
   - **저장하면 기존 명단은 통째로 교체된다**
   - 뒷 4자리가 겹치면 뒤엣것을 버리고 어떤 번호가 겹쳤는지 알려준다
3. **객실 수량** 확인 (기본값이 이미 5/5 · 8/7 · 8/7)
4. 고객에게 링크 문자 발송
5. 현황은 관리자 화면에서 새로고침해 보고, `표 복사` 로 엑셀에 붙여넣는다

## 5. 알아둘 것

- 선택을 되돌리려면 관리자 화면 표에서 그 줄의 `✕`. 그 자리는 다시 열리고 그 사람은 다시 고를 수 있다.
- 명단에 없는 번호는 못 들어온다. 현장에서 추가하려면 명단에 그 줄을 넣고 다시 저장한다.
- **뒷 4자리가 겹치는 예매자**는 지금 뒤엣사람이 버려진다. 겹치는 사람이 실제로 생기면 알려주면 이름까지 같이 묻는 방식으로 바꾼다.
- 데이터는 R2의 `booking/` 밑에 있다 (`roster.json` 명단 · `stock.json` 수량 · `bk/<뒷4자리>.json` 선택 1건).

## 6. 손대기 전 검증

```
cd apps/booking && node test.mjs
```
28가지를 실제로 돌려본다(인증·구분별 재고 격리·중복 차단·동시 클릭 정원 초과 방지·관리자 잠금).
고치고 나서 이게 전부 통과해야 한다.
